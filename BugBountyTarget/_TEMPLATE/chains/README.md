# Chains

One file per multi-primitive chain. Every link carries its status:

| # | Link | Status |
|---|------|--------|
| 1 | ... | Verified on device |
| 2 | ... | Verified on device |
| 3 | ... | **Unproven** — requires ... |

**Two verified links plus one unproven link is a Medium with a stated precondition, not a Critical.**

Files are named `X-NNN.md` (START.md §6 ID grammar: chain `X-NNN`; `C-NNN` is a component instance, never a chain).
