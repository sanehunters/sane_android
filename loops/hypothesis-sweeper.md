# hypothesis-sweeper — every 30 minutes during P7

```
/loop 30m List <eng>/hypotheses/*.md not yet marked RESOLVED. Pick the highest expected value (ceiling ×
confidence ÷ cost). Run one VERIFY → DEEPEN → ESCALATE step and record the outcome in the stub and in
chains/C-0NN.md. Mark RESOLVED (finding F-0NN, or conceded with the reason it is bounded) when settled.
Stop this loop when no unresolved hypothesis remains.
```
